# Atelier room packs

Each TOML file is an independent data-authored profile over the canonical
content-addressed capability-pack graph. Routes name existing owners; they are
navigation, not copied implementations. Every profile declares its own input
and output Shapes, authority ceiling, claims, surface, degradation, fallback,
and checked specimen.

Every pack also declares its continuity request as data. The default lane is a
phone Scene with keyboard or touch semantic input and no body prompt. Pack
content is projected only after mission, passport, route-lease, and endpoint
grants intersect; sensitive fields are denied on reduced, audible,
notification, and lock-screen roles.

The toy color room is deliberately ordinary pack data. Its presence proves that
another room requires neither an SDK runtime type nor a kernel or bootloader
change.
