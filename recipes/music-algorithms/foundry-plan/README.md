# Load the modular music algorithm foundry

This SDK recipe loads the five frozen candidate crates individually, then
reproduces the foundry's data-only analyze, transform, and render plan. The
facade contributes feature selection and curated Rust names only: signal
processing, bounded search, exact ratios, consonance, and counterpoint remain
owned by their focused crates.

The work, frontier, result, seed, and deadline bounds stay visible in the plan.
Placement remains the ordinary `realize` choice; the SDK adds no music-specific
scheduler, planner, provider, or compatibility dialect.
