# Compose a quiet week from copied claims

This deterministic specimen projects seven days through the daily cadence pack.
It includes a three-card burst, stale evidence, refused disclosure, a no-input
day, locked and revoked lanes, unavailable model and device placements, a paper
flock path, and a removed media pack. Every input is a copied claim or status;
the cadence owns no source truth and receives no source handle.

Run `python3 tests/validate_cadence_pack.py` from the SDK checkout. The proof
checks the three-card and two-minute daily ceilings, the twenty-second flock
path, explicit finance reconciliation, and every channel disclosure ceiling.
