# Adopt and subtract a stewardship composition

This data-only specimen composes the existing workshop, pack graph, journal,
book, adoption transaction, rollback, sealed lanes, and mutual porch. Start
from a human-reviewed BRIDGE brief, preview every authority and lifecycle lane,
then commit one atomic adoption receipt.

`composition.toml` is deliberately generic and contains no household values.
It proves that rebuild depends only on adopted roots and retained source
content, not chat, model cache, derived views, or workshop scratch. Subtraction
is a new atomic revision: a retired field and pack disappear from the closure,
projection, grants, and recipe roots. Tombstones prevent journal replay from
restoring either item after their retention action completes. Declining the
optional mutual-porch invitation is a successful terminal outcome.

Run `python3 tests/validate_adopt_subtract_composition.py` from the repository
root for the deterministic proof.
