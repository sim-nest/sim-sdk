# Rebuild a cited garden season

Rebuild spring from authored bed, crop, event, and dated citation data. The
fresh citation remains a recommendation, the expired citation becomes a next
question, and the chosen care action gets only a non-authoritative calendar
projection. A fresh confirmed pea harvest is copied as a value claim without
opening the kitchen. Add the herb bed and dill crop by extending input data;
kitchen, calendar, model, and network providers are not required.
