# Keep only chosen media traces

This offline specimen imports one explicitly selected export entry, records a
position and Mia-authored note, then removes the trace and its derived local
search entry. It does not contact a media service, scrape a work, infer a taste
profile, or treat playing and saving as understanding, endorsement, or finish.

Run `python3 tests/validate_media_reference_packs.py` from the SDK checkout.
