# Execute the stewardship memo acceptance matrix

This entirely synthetic, offline specimen turns the four current stewardship
memo families into checked evidence without copying a person's facts into the
public repository. `matrix.tsv` classifies every substantive promise as a
checked specimen, an exact unsupported state, or a manual path. The stable
promise ids, rather than private memo prose, are the public acceptance contract.

`statement.csv` is a realistic semicolon-delimited bank export. `odb.script`
is the relevant HSQLDB text member of a synthetic ODB book. `scenario.tsv`
composes those sources with a kitchen week, garden season, eight-bird flock,
optional private log, chosen media traces, deterministic fake-model dialogue,
the workshop, a prepare-only support crew, and the complete reversible
lifecycle. Both source inputs remain immutable; every consequential decision
is explicitly human-authored.

Run `cargo test --manifest-path tests/memo-acceptance-focused/Cargo.toml`. The
test also audits every public specimen for forbidden private values and rejects
unqualified destruction claims: managed crypto-erasure means that tracked
ciphertext generations and backups lose their managed keys, not that every
possible copy in the world is destroyed.
