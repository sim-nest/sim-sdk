# Keep and erase a private observation

This networkless recipe opts into only three fields, enters an exact event and
a human-authored meal note, then previews a selected professional-review export.
The default export is locally encrypted. Plaintext requires Mia to acknowledge
the pack warning explicitly.

The pack is absent until activated. Every payload belongs to the sealed
`private-observation` lane. Lock, revoke, or managed-generation destruction
removes plaintext from pack access and derived views; destruction claims only
that the generation is unreadable, not that physical storage media was erased.
No operation diagnoses, infers causes, treats, prescribes, recommends, scores
adherence or risk, sets targets, or proposes a restrictive diet.
